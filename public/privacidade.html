Política de Privacidade

Aplicativos e ferramentas pessoais de Jair Lima · Última atualização: 15 de outubro de 2026

Esta política descreve como os aplicativos, extensões e ferramentas de uso pessoal desenvolvidos por Jair Lima tratam dados. Ela vale para todos eles, inclusive os que acessam serviços do Google em nome do próprio autor.

1. Quem trata os dados

O responsável é Jair Lima, pessoa física, que desenvolve e utiliza essas ferramentas em caráter pessoal. Contato: jairslima@gmail.com.

2. Quais dados são acessados

As ferramentas acessam apenas os dados estritamente necessários para a função que executam. Conforme o caso:

  • Contatos do Google: leitura e edição da própria agenda de contatos do autor, incluindo nomes, telefones, e-mails e datas de aniversário, para manter a agenda organizada e atualizada.
  • Arquivos locais: arquivos no próprio computador do autor, quando a ferramenta precisa processá-los.
  • Dados de uso técnico: informações necessárias para o funcionamento, como preferências e registros de execução, mantidos apenas no computador do autor.

3. Para que os dados são usados

Exclusivamente para executar a finalidade da ferramenta: organizar e atualizar a agenda de contatos, processar arquivos locais e gerar os resultados que o próprio autor solicitou. Nada além disso.

4. Com quem os dados são compartilhados

Com ninguém. Os dados não são vendidos, alugados, compartilhados, transferidos nem cedidos a terceiros. Não há publicidade, rastreamento de comportamento nem uso dos dados para treinar modelos de terceiros.

5. Onde os dados ficam armazenados

As credenciais de acesso ficam em arquivos locais, no computador do autor, protegidos pelo sistema operacional da própria máquina. Os dados tratados permanecem no computador do autor ou na conta Google do próprio autor. Não existe servidor intermediário operado pelo desenvolvedor, nem banco de dados remoto.

6. Dados do Google e uso limitado

O uso das informações recebidas das APIs do Google obedece à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use). Em resumo: os dados do Google são usados somente para as funções visíveis ao usuário, não são transferidos a terceiros, não são usados para publicidade e não são lidos por pessoas, exceto quando o próprio usuário solicitar, quando exigido por lei ou por segurança.

7. Retenção e exclusão

Os dados são mantidos enquanto forem úteis à finalidade. O autor pode apagar qualquer dado a qualquer momento, diretamente na ferramenta ou na sua conta Google. Para solicitar a exclusão de dados ou revogar o acesso de qualquer ferramenta, basta remover a permissão em myaccount.google.com/permissions ou escrever para o e-mail de contato.

8. Segurança

O acesso às contas é feito por autenticação OAuth do próprio provedor, sem armazenamento de senha. As credenciais ficam em arquivos locais, fora de repositórios públicos, e o acesso à máquina é protegido pelo sistema operacional.

9. Menores de idade

As ferramentas são de uso pessoal e não se destinam a menores de idade, nem coletam dados de crianças.

10. Alterações desta política

Esta política pode ser atualizada para refletir mudanças nas ferramentas. A data de última atualização no topo desta página sempre indica a versão vigente.

11. Contato

Dúvidas sobre esta política ou sobre o tratamento de dados: jairslima@gmail.com.
